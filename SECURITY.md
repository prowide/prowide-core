# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, or in a third-party
component distributed with it, please report it privately to:

**cybersecurity@prowidesoftware.com**

This is Prowide's contact address for reporting vulnerabilities and security
incidents in our products.

Please do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.

When reporting, it helps to include:

- The affected project and version
- A description of the issue and its potential impact
- Steps to reproduce, or a proof of concept, where possible
